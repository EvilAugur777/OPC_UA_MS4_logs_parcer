# OPC UA MS4 Logs Parser

Консольная утилита для анализа логов OPC UA клиента (системы MS4D). 
Скрипт быстро прогоняет текстовые логи, находит записи вида `OPCUA Client. St="..." ... items=...` и вычисляет статистику по количеству `items` для каждого файла.

Это позволяет наглядно оценить производительность OPC UA клиента при разных настройках в рамках одной общей таблицы.

## 📊 Что выводит программа

Утилита формирует сводную таблицу в консоли со следующими колонками:

* **Файл** — имя анализируемого лога (ищутся файлы с расширением `.txt`).
* **Записей** — количество найденных рабочих записей (нулевые значения `items=0` игнорируются, так как обычно означают сброс или инициализацию).
* **Среднее items** — обычное математическое среднее количество `items` за запись в логе.
* **Мин items** — минимальное значение `items` (позволяет увидеть худший цикл и выявить просадки).
* **Ср. за 100мс** — среднее количество `items` в пересчете на один цикл сервера (100 мс). Вычисляется как `Среднее items / 600` (10 циклов в секунду × 60 секунд).
* **Мин за 100мс** — минимальное количество `items` в пересчете на один цикл (100 мс). Вычисляется как `Мин items / 600`.
* **Медиана (10%)** — усеченное среднее. Из общего списка значений отбрасываются 10% самых низких и 10% самых высоких показателей, а по оставшимся 80% считается среднее. Это отфильтровывает случайные выбросы и дает более честный показатель рабочей нагрузки.
* **Мед. за 100мс** — медианное (усеченное) значение в пересчете на один цикл (100 мс). Вычисляется как `Медиана (10%) / 600`.

Все дробные значения округляются до целых чисел для удобства чтения.

## 💾 Сохранение отчетов (Экспорт в CSV)
После завершения анализа программа предлагает опционально сохранить отчет.
* **Куда сохраняется:** В ту же папку, где лежат анализируемые логи.
* **Имя файла:** Формируется автоматически с временной меткой: `report_YYYYMMDD_HHmmss.csv`.
* **Удобство:** Файл создается в кодировке UTF-8 с BOM, поэтому он сразу корректно открывается в Microsoft Excel без проблем с русскими символами. После сохранения утилита предложит мгновенно открыть файл.

## 🚀 Как запустить

### Вариант 1: Готовый `.exe` (Портативный)
Если вы не хотите собирать проект самостоятельно, скачайте готовый исполняемый файл в разделе **[Releases](../../releases)**. 
Он собран как *Self-Contained Single File*, поэтому **не требует установки .NET Runtime** на компьютере.

1. Запустите `OPC_UA_MS4_logs_parcer.exe`.
2. Вставьте полный путь к папке с вашими `.txt` логами (можно скопировать прямо из адресной строки Проводника).
3. Нажмите `Enter` и дождитесь результата.

### Вариант 2: Сборка из исходников
Если у вас установлен .NET SDK:
1. Клонируйте репозиторий.
2. Откройте терминал в папке проекта.
3. Выполните команду:
   ```bash
   dotnet run
   ```

### Вариант 3: Оптимизированная сборка портативной версии
Чтобы собрать утилиту в один независимый `.exe` с максимальной скоростью работы (как в релизах):
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true -p:EnableCompressionInSingleFile=false -p:OptimizationPreference=Speed
```
